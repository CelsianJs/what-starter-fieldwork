# Fieldwork

Fieldwork is a What Framework starter for a computational research lab or artistic AI journal. It is intentionally AI-adjacent but truthful: the field drawing is a deterministic browser algorithm, not live inference.

## Quick start

Use Node.js 22.x. After `npm ci`, install Chromium once before running the browser smoke test: `npx playwright install chromium`.
On minimal Linux CI images that do not already include browser system libraries, use `npx playwright install --with-deps chromium` instead.

```bash
npm ci
npm run dev
```

Open the local Vite URL, then try:

- `N`, `M`, and `R` on the homepage canvas.
- `/projects`, then filter by Language or Tools.
- `/projects/radio-garden` for a deep research route.
- `/build` for an agent-readable implementation guide.

## Scripts

```bash
npm run dev          # local Vite dev server
npm run build        # production build plus static route aliases
npm run preview      # serve the production build locally
npm test             # Vitest unit coverage
npm run smoke        # Playwright browser flow and screenshots
npm run deploy       # Vura preview deploy, requires auth
npm run deploy:prod  # Vura production deploy, requires auth
```

## What it demonstrates

- What Framework signals and computed values in `src/state/gallery.js`.
- Router-driven static shell routes in `src/routes.jsx`.
- Effect cleanup for keyboard and resize listeners in `src/components/GenerativeCanvas.jsx`.
- Static Vura aliases generated by `scripts/generate-static-aliases.mjs`.
- No tracking, paid AI, remote images, or hidden credentials.

## Deploy notes

The source is available at [CelsianJs/what-starter-fieldwork](https://github.com/CelsianJs/what-starter-fieldwork). To deploy your own copy:

```bash
npm ci
npx vura-platform login
npx vura-platform projects create fieldwork --team <your-team-id>
npm run build
npx vura-platform deploy --prod
```

Known static aliases are generated from the project dataset, including every project detail route, `/projects`, `/build`, and `/404`. A root `404.html` supplies the production not-found response. The pages are client-rendered shells, not server-rendered research content. Vite's local preview uses SPA fallback; Vura's static project serves only the emitted routes and returns HTTP 404 for unknown paths.
